              字段说明
              

                
模板 ID
已保存模板的数据库 ID，新建时为空。

                
名称
用于在模板列表中识别来源站点或规则用途。

                
URL 模板
抓取地址，分页时可使用 {page} 和 {size} 占位符。

                
请求方法
目标站点要求的 HTTP 方法，支持 GET 和 POST。

                
默认协议标签
页面只给出 IP:端口时按这些协议展开候选代理。

                
页码模式
固定范围按起止页抓取；全部页会先请求起始页并识别最大页。

                
起始页/结束页/每页数量/最多页数
控制分页范围；{size} 留空时替换为空，自动识别页数时最多页数用于防止无限抓取。

                
请求超时秒数
单个页面请求超时时间，0 表示使用全局请求超时。

                
并发页数
同时抓取的页面数量，数值越大对目标站点压力越高。

                
失败重试次数
页面请求失败后额外重试次数。

                
失败自动停止
页面失败累计达到该值后停止剩余页面，0 表示不自动停止。

                
页数识别正则/分组
从起始页响应里提取最大页码，分组可写命名组 page 或数字组 1。

                
scheme/host/port/user/password 分组
提取正则中的字段分组名；scheme 为空时使用默认协议标签。

                
请求头/请求体
请求头每行一个，格式为 Header: value；POST 请求体支持 {page} 和 {size} 占位符。

                
提取正则
从响应文本中匹配代理，至少需要 host 和 port 分组。

                
抓取出口/指定代理
控制抓取目标网站时使用直连、代理池或指定代理。
